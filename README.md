# SmartLocal

Intelligent Location-Based Service Platform.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Current version

This is the frontend prototype with realistic mock data. It is deliberately structured so the next stage can connect REST APIs and databases.

### Planned CO mapping

- CO1: MySQL/PostgreSQL relational data, SQL queries, joins, transactions.
- CO2: MongoDB geospatial data + vector search for semantic discovery.
- CO3: FastAPI REST APIs and Pydantic validation.
- CO4: Node.js/Express and Spring Boot services.
- CO5: Microservices, REST communication and Kafka events.
- CO6: Docker and GitHub Actions CI/CD.

No paid API is required for the current frontend.
